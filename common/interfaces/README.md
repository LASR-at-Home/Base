# Interfaces - Physical UI

This package provides a physical interaction interface for the robot. It allows an user to interact with the system through a web UI connected to ROS 2 using rosbridge.

## General use

The main use is for users to start and operate tasks without a custom operators (for example, referres and volunteers during RoboCup)

It can also be used as a backup interface if Speech-To-Text inputs are unavailable or unreliable.

**Ran using launch file**, 

## Current use:
 1. **Use in HRI task** - Starting the task

 2. **Old use in GPSR** - Confirming the provided command and locking SST input between commands.

 3. **Restaurant** - Selecting items for the order and confirming order
